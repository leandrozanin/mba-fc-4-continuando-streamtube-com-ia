### SI-03.6 — Resume, Complete and Abort Upload; Enqueue Processing
- **Status:** completed
- **Tests:** `src/videos/videos.service.spec.ts`, `src/videos/videos.service.integration-spec.ts`, `test/videos.e2e-spec.ts`
- **Observations:** S3 accepts completing with a subset of the parts, so `completeUpload` first checks that parts `1..partCount` are all listed (400 without touching S3). If the assembled object still differs from the declared size, the object is discarded and a new multipart upload is opened (the client re-signs and re-sends). After an enqueue failure the row returns to `draft` with the object already assembled; a new `complete` only retries the enqueue.
